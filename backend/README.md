# 🚀 MERN Expense Tracker with Analytics

A full-stack application to track daily expenses with data visualization.

## ✨ Features
* **Authentication:** Secure Login & Register using JWT.
* **Visual Analytics:** Multi-color Pie Chart with internal labels for transactions.
* **Real-time Updates:** Instant balance and history updates.
* **Tech Stack:** MongoDB, Express.js, React.js, Node.js.

## 🛠️ Setup Instructions
1. Clone the repo.
2. Run `npm install` in both `frontend` and `backend` folders.
3. Start Backend: `node server.js` (on port 5000).
4. Start Frontend: `npm start` (on port 3000).
